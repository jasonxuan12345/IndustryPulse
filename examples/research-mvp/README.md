# 公开披露研究样例

这是2026-10-28本地验收使用的煤炭、油气、农副食品、专用设备四行业归档。摘录来自公开官方披露，密钥、生产数据库和私人设置不包含在此目录中。

`frozen_inputs.json` 保留20行业扫描信息，历史输入裁剪到各序列近期3个所属期及各资产最近70根行情，降低仓库体积。它是事后重建样例，不是严格历史PIT，也不是新用户的实时投资建议。`tool_archive.json` 用于离线重放搜索、读取和模型的既有结果，不会发起API调用。

从项目根目录执行：

```sh
python scripts/verify_mvp_delivery.py
```

脚本验证原文hash、摘录位置、发布时间、四行业覆盖、连续3次执行、幂等观察入账和单次搜索故障降级。输出写入 `artifacts/`；原始样例不被改写。四条建议均为WATCH。
