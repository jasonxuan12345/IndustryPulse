# IndustryPulse 可视化设计

## 目标与布局

个人行业研究工作台，一眼区分市场趋势、信息事件与研究证据。默认半导体视角。
桌面使用 220px 固定导航 + 弹性主区；主区上方为搜索、时间窗口、刷新，随后是领域切换、四张核心指标卡、趋势主图与资金流排行、新闻流与公司观察。窄屏改为单列。

## 视觉

石墨黑底、青绿色主色、紫色辅助线、上涨绿/下跌红；细边框卡片、大号数字、紧凑中文排版。入场错峰动画、SVG 曲线绘制、悬停提示、侧滑详情；遵循减少动画系统偏好。无需外部字体/CDN。

## 信息结构和交互

- 总览：指标、可切换时间范围的双序列图、资金排行、热点、新闻与公司事件。
- 趋势与资金：更大趋势图、分领域资金流，单位和统计口径显式展示。
- 资讯中心：新闻/热点/人事筛选、搜索、详情、来源链接、收藏。
- 公司观察：公司筛选、公司新闻和高管事件。
- 研究数据：展示本机 DuckDB 真实序列与出处；当前值浏览，明确不是严格 PIT。
- 数据接入：当前模式、更新时间、接口结构、JSON 导入、数据导出；连接异常单独显示，不悄悄换成模拟数据。

## 数据边界

资讯默认是明确标注的虚构演示，不冒充最新新闻。接入统一 provider JSON 后各模块整体切换为真实接口数据；服务器环境变量配置远程 URL/令牌，或页面导入 JSON 文件，无需修改前端。真实经济数据独立读取现有本地数据库。

## 实现

现有 FastAPI 托管静态 HTML/CSS/JS 和新增 /api/dashboard 路由；保留原冻结 /v1 合同与旧 Streamlit。零前端构建依赖。本地运行，不新增云托管。
