# 内置公开资讯源

## 直接使用

1. 启动软件，进入「数据接入与设置」。默认已经启用推荐源，不需要再填资讯 API。
2. 在顶部选择领域，例如半导体，再选择芯片设计、晶圆制造、设备与材料、封装与存储。
3. 勾选要在该行业生效的来源，点「保存选择并启用」。其他行业的勾选独立保存。
4. 可按语言、接入类型、名称筛选，批量勾选筛选结果，或为整个领域启用推荐/停用。
5. 抓取结果会自动出现在资讯中心。可以再按细分行业、来源、时间窗口筛选。
6. 新闻详情保留摘要和原文链接，可用已配置的默认 AI 模型解读；采集不调用模型、不消耗模型额度。

默认模式为内置真实资讯，只有手工选择演示模式才展示虚构内容。无真实行情时，涨跌、
资金流、热度与价格曲线留空；不会从新闻或模型补造。公司关联与行业归类是关键词匹配，
不是专业实体识别或人工审核结果。主题新闻搜索能补充多家中文媒体，但不是单一官方来源。

## 覆盖

102 个订阅通道，含 58 个直接 RSS/公开接口、14 个 RSSHub 通道、30 个行业新闻搜索。
这是通道数，不是独立媒体数；同一发布方可能有多个栏目。

12 个领域：半导体、人工智能、新能源、钢铁、医药生物、有色金属、化工与能源、
汽车与出行、通信与软件、消费与供应链、金融与资本市场、宏观与政策。共 30 个细分行业。

包括 IT之家、36氪、钛媒体、极客公园、雷峰网、InfoQ、中新网、华尔街见闻、
财联社、第一财经、虎嗅、量子位、证券时报、界面、Semiconductor Engineering、
EE Times、DIGITIMES、NVIDIA、Arm、三星、意法半导体、Hugging Face、Google Research、
OpenAI、MIT、CleanTechnica、Electrek、世界钢铁协会、Mining Weekly、STAT、WHO、

## 数据与更新

- 程序首次读取资讯时在后台采集，界面显示进度；默认 15 分钟更新，可设 5 分钟至 24 小时。
- 同一个来源同时被多个行业启用，只抓取一次。单次最多并发 8 个源，不请求每篇全文。
- RSS/Atom、公开网页 JSON 和 RSSHub 转换均保留发布方、短摘要、原文与发布时间。
- 单源最多保留 300 条、180 天缓存。同 URL 在同一领域去重，保留各细分行业归属。
- 缺失发布时间时标为「首次发现」，刷新不会把发现时间改成最新发布时间。
- 单源失败不影响其他源；保留上次成功内容并显示错误及最后成功时间。不会降级成演示。
- 空订阅、连接失败和成功有内容分别显示。没有相关行业报道，不等于来源连接失败。
- `data/news/settings.json` 保存选择，`data/news/cache.json` 保存缓存，均不入 Git。
- 修改 `config/news_sources.yaml` 可扩充目录；`INDUSTRYPULSE_NEWS_DIR` 可切换本地目录。
- 关闭启动器会停止采集线程和全部服务。重启沿用来源选择与缓存，自动重新抓取。

自定义 JSON 模式和原有 `INDUSTRYPULSE_FEED_URL` 继续兼容。显式配置远程环境变量时远程优先，
需要移除该变量并重启才由内置源供数。已有导入文件默认兼容；保存内置模式可切回公开采集。

## 来源研究与可用性

来源发现参考发布方 RSS 与这些开源目录；适配器为本项目独立实现，没有复制开源项目业务代码：

- [Plenary awesome-rss-feeds](https://github.com/plenaryapp/awesome-rss-feeds)
- [zerahchu/rsslist](https://github.com/zerahchu/rsslist)
- [RSSHub](https://github.com/DIYgod/RSSHub)
- [NewsNow 的华尔街见闻适配依据](https://github.com/newsnext/newsnow/blob/main/server/sources/wallstreetcn.ts)

2026-10-22 本机逐通道发起了真实请求，初次 102 个通道中 88 个读到条目、1 个空订阅、13 个失败；
随后修正旧路由与个别 XML 控制字符并补测：98 个成功有内容，1 个空订阅，
2 个连接失败，1 个连接失败但有历史缓存。已启用源整理出 3898 条领域资讯记录
（跨领域归属会重复计数）。本轮全量测试 463 项通过，Ruff 与 Mypy 通过。
这个结果不是未来可用性保证，界面实时状态为准。
RSSHub 使用预置的社区实例 `https://rsshub.bestblogs.dev`，受第三方实例可用性影响，可在高级选项更换。
部分官方站会临时返回反爬或地区限制；不绕过登录、验证码或付费墙，不把受限源伪装成可用。
原文版权属于各发布方，软件仅作为个人订阅阅读器，展示短摘要与链接，不提供付费全文。
