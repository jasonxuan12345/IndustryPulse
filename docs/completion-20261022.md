# 原系统功能整合交付（2026-10-22）

本轮按原 136 项任务逐项建立工程实现对账，见 `planning/task_status.csv`。
“实现”表示已有程序入口或可执行模块，不等于全部外部来源、人工审阅和真实效果验收已经通过。

## 现在可直接使用

- 一个首页整合资讯、宏观总览、行业景气、模型预测、研究实验、ETF 回测、证据审查、数据版本和运维任务。
- 宏观/景气支持三研究模式、冻结快照和历史时点；六维雷达、动量、广度与原件来源可见。
- T1 生产景气/所选指标方向与 T2 同年第三次有效发布利润率目标；标签公布时间参与训练过滤。
- M00–M07 八类模型：末值、季节性、AR、Logit、Elastic、DynamicFactorMQ、LightGBM、Markov。
- 半年扩展窗滚动实验、purge/embargo、共同 OOS、分年/分行业、区块 bootstrap、失败模型报告与工件指纹。
- 独立窗口校准、训练窗领先滞后探索、在线 CUSUM、价差代理，以及未来 holdout 封存、排除和结束后评估流程。
- ETF 月末信号、次日开盘、成本/仓位约束、分红入账、基准净值、逐笔交易和风险指标。
- 候选导入、官方公告发现、可配置搜索/抽取 HTTP 服务、原件核验、审核日志与审查后发布。
- 完整数据包导入导出、历史版本查看、Parquet/Bronze 备份、hash/行数核验恢复、后台任务与可持久化本地调度。
- FRED/ALFRED、海关 HS 版本化导入、AKShare 备用文件 schema 检查；18 源接入与覆盖报告。

## 实际数据与运行

- 已有官方原件复用到煤炭、化工、有色矿采选、有色冶炼；两个有色机制独立配置，煤种/化工产品异质性在配置中说明。
- 本机目前 39 条序列、2142 个观测版本、148 份原件、7016 条 ETF 日线、27 笔公司行动。
- 钢铁指标方向预测当前使用 43 个已公布标签；T2 利润率样本 21 个。
- 已执行真实扩展窗实验，16 个共同 OOS；预测仍未验证，统计模型概率不是投资胜率。
- 当前完整快照重跑基线回测可以与旧报告不同：新旧报告分别保留参数、输入快照和结果，不覆盖历史。
- 固定本地 catalog + 三个月景气计算测得约 3.53 秒，Python 峰值跟踪内存约 44.46 MiB；机器/快照不同不可直接比较。

## 不可冒充完成的外部验收

- 没有提供的供应商 API Key、授权数据和真实新闻不会凭空出现；已提供可运行适配入口。
- 海关许可、部分其他来源的授权判定、目标财务口径专家签核仍需真实的人完成。
- ETF 现有主表的上市日是行情下界估计；正式历史主表核验仍待官方记录。
- 30 文档审计包与核对工具已就绪，但独立人工标注尚未完成，不能声称金样本验收通过。
- STRICT 历史同期证据不足只能前向累积；未来 holdout、概率校准与高级模型的真实有效性需要新样本。
- 无远端时不能执行真实 GitHub Actions 矩阵。本轮是本地 Windows 工程验证。

启动、接口、研究工具和故障处置见 `docs/operations.md`。没有新增真实交易下单功能。
