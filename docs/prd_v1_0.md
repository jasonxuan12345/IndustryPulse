# 鸿蒙纯本地护照与签证管家 App — 产品需求文档（PRD v1.0）

**文档版本**：v1.0  
**目标平台**：HarmonyOS NEXT（纯血鸿蒙 / 鸿蒙 5+）  
**核心定位**：Local-First（纯本地优先）的硬核出入境证件管家与行前合规防呆助手  
**商业模式**：免费版（基础额度）+ Pro 终身买断制（IAP 内购）

---

## 一、 项目背景与市场机会

### 1.1 市场现状与竞品短板分析
目前市面上已有若干护照与签证记录工具，但普遍存在“信息孤岛”、“只记不防呆”以及“纯血鸿蒙原生缺位”等问题：

| 竞品类型 / 代表产品 | 现有优势 | 核心痛点与机会缺口 |
| :--- | :--- | :--- |
| **护照免签查询类**<br>（如 Passport Index） | 全球护照免签排名、国家签证政策覆盖广 | 1. 仅按“护照国籍”静态算免签，**不支持“护照 + 已有高含金量签证（美/日/申根等）”叠加解锁计算**<br>2. 无个人证件管理、无有效期/空白页/关联签注提醒 |
| **基础到期提醒类**<br>（如 Visa & Passport Expiry） | 轻量录入护照/签证到期日，支持基础倒计时 | 1. 本质是“带倒计时的相册”，缺乏真实出入境规则校验<br>2. 无法处理**新旧护照同时携带、EVUS 电子登记联动、申根滚动停留天数**等高危拒载风险 |
| **国内签证/出行记录类**<br>（如签证钱包、航旅纵横） | 贴合国内用户习惯，或具备航班同步能力 | 1. 多为强联网/云端账户模式，高净值用户对**上传护照敏感原图存在强烈隐私顾虑**<br>2. 缺乏防盗用水印外发、离线边检通关卡等高频实用工具<br>3. 纯血鸿蒙原生体验与桌面卡片/实况窗适配薄弱 |

### 1.2 生态与客群红利
* **硬件与客群高度重合**：HarmonyOS NEXT 早期主力机型（Mate / Pura / 折叠屏系列）用户与国内常旅客、商务人士、高频出境游家庭高度重叠，具备**高净值、高隐私敏感度、强工具买断意愿**三大特征。
* **原生系统能力红利**：充分利用纯血鸿蒙的桌面服务卡片（Form Kit）、实况窗（Live View Kit）、本地 NFC 读芯与端侧 AI 视觉能力，极易形成差异化口碑并获取应用市场早期流量扶持。

## 二、 产品定位与核心价值主张

* **一句话定位**：不只记到期日，更帮你**算清能免签去哪、防住机场被拒载、守住证件零泄密**的鸿蒙原生证件管家。
* **四大核心原则**：
  1. **Local-First 极致隐私**：核心证件数据与原图 100% 加密存储于设备本地，不强制登录账号、不上传云端，彻底消除隐私焦虑（辅以用户自控的本地加密备份包解决换机痛点）。
  2. **防呆优先于记录**：围绕“避免几千元机票因证件细节作废”设计规则校验，化被动查询为主动预警。
  3. **高频场景破圈**：将低频的“看护照有效期”延伸至高频的“给酒店发脱敏水印图”、“机场过关一键亮码”、“桌面看倒计时”。
  4. **纯血鸿蒙原生质感**：深度融合实况窗、服务卡片、NFC 碰一碰与系统级防截屏隐私保护。

## 三、 v1.0 核心功能架构与详细需求

### 模块 1：极致建档引擎（MRZ 机读码扫描 + NFC 芯片读取）
解决传统手动输入繁琐、普通 OCR 易混淆 `0/O`、`1/I` 的痛点，同时打造极客传播爆点。

1. **MRZ 机读码极速识别（基础建档）**
   * 调用鸿蒙端侧 `Core Vision Kit`，支持相机扫描护照首页底部两行（TD3 标准）及贴纸签证底部（TD2/MRV-A/B）机读码。
   * 自动执行 ICAO 9303 校验位算法，毫秒级解析：护照号、姓名（拼音）、国籍、性别、出生日期、签发国、有效期，确保零错字。
2. **NFC 电子护照芯片读取（v1.0 旗舰亮点）**
   * 扫描 MRZ 获取 BAC（基本访问控制）密钥后，引导用户将新版电子护照（E 开头等带芯片标识）贴近手机背面 NFC 感应区。
   * **读取内容**：
     * 芯片内精准个人身份字段（DG1）。
     * **无压缩高清彩色证件照原图提取**（DG2），自动设为 App 内证件头像，可替代模糊的手机翻拍照。
     * 芯片数字签名校验状态展示（可视化“电子芯片已验真”徽章）。
3. **全字段证件档案管理**
   * **支持证件类型（v1.0）**：护照、各国贴纸/电子签证、港澳通行证及签注、台湾通行证、身份证/驾照辅助页。
   * **精细化字段**：签发日、到期日、入境次数（单次/两次/多次/剩余次数）、单次最长停留天数、是否已激活使用、关联电子文件（PDF/图片附件）。

### 模块 2：「主证 + 副证 + 旧护照」血缘关联防呆引擎（核心差异化 #1）
专治真实出行中最易导致“值机被拒”的隐形关联坑。

1. **电子登记（副证）自动挂载与联动预警**
   * 录入特定长期签证时，系统自动提示并挂载对应电子旅行授权节点：
     * **十年美签** $\rightarrow$ 自动挂载 **EVUS（2 年有效期）** 登记记录与倒计时。
     * **加拿大/英国/申根签** $\rightarrow$ 预留并支持挂载 **eTA / 未来 ETIAS** 等电子授权节点。
     * **港澳通行证** $\rightarrow$ 将**卡面有效期**与**香港/澳门签注剩余次数及签注有效期**解耦管理，分别倒计时。
2. **新旧护照换发血缘绑定**
   * 当用户录入新护照并将旧护照标记为“已换发/归档”时，系统自动扫描旧护照名下是否仍有**未过期的有效长期签证**（如十年美签、加签、日签）。
   * 若检测到有效长签，自动建立**新旧护照血缘关联**，并在涉及该签证的详情页、桌面卡片与通关卡片上高亮标红警告：
     > **⚠️ 同带预警**：此签证贴于旧护照（尾号 XXXX），出行时**必须同时携带新、旧两本护照**；若为美签，请确认已使用**新护照号**重新完成 EVUS 登记。
3. **行前基础合规校验**
   * **6 个月有效期红线预警**：护照剩余有效期不足 180 天（6 个月）时，全局进入黄色/红色提醒状态，明确提示大部分国家及航司将拒绝登机。
   * **申根 90/180 天滚动额度计算（基础版）**：录入申根出入境记录后，自动计算任意 180 天滚动窗口内已停留天数与剩余可用天数，支持输入“计划出行日期”进行简单的合规预演。

### 模块 3：实体护照「空白页余量」可视化追踪器（核心差异化 #2）
解决高频出境人士临送签或过关才发现“缺少连续空白对开页”的痛点。

1. **页码网格可视化视图**
   * 支持按护照规格初始化页数（默认 48 页，可选 32 页/64 页），排除首页与备注页后生成可视化双页对开网格。
   * 用户每次获得新贴纸签或盖满一页出入境章，点击对应页码标记状态（空白 / 已贴签 / 半满 / 已满）。
2. **智能余量阈值预警**
   * 实时统计“剩余总空白页数”与“剩余连续空白对开页组数”。
   * 当空白页 $\le 4$ 页或无连续 2 页空白对开页时，触发预警：“空白签证页告急，申请申根/日本/南非等签证可能受阻，建议提前规划换发新护照”。

### 模块 4：一键「防盗用水印 + 局部脱敏」安全外发引擎（核心差异化 #3）
将低频证件 App 转化为高频实用工具，用实际体验建立“极致隐私”的品牌心智。

1. **防 AI 擦除全屏水印**
   * 查看任意护照/签证扫描件时，点击「安全外发」进入出图模式。
   * 快捷用途标签（如：`仅用于酒店入住登记`、`仅用于签证代办审核`、`仅用于机票预订核验`、`自定义输入`），自动附带当日日期。
   * 本地 Canvas 实时渲染**全屏倾斜交错平铺水印**，支持微调透明度与字号，兼顾“可看清关键信息”与“防止被恶意截取盗用”。
2. **敏感区域一键局部打码**
   * 提供快捷勾选开关，支持自动或手动框选遮挡高敏字段：
     * `[ ] 遮挡人像照片`
     * `[ ] 遮挡持照人签名栏`
     * `[ ] 遮挡底部 MRZ 机读码`
     * `[ ] 遮挡身份证号 / 出生地`
3. **零相册残留直出**
   * 生成的水印脱敏图仅存在于应用沙盒临时内存区，直接拉起鸿蒙系统分享面板（`Share Kit`）发送至微信、邮件或华为分享。
   * **默认不写入系统公用相册**，分享完成后即刻销毁临时文件，真正做到“过手不留痕”。

### 模块 5：离线「海关通关卡片」+ 纯血鸿蒙实况窗（核心差异化 #4）
攻克“无网国际航班填写入境卡”与“边检柜台手忙脚乱翻找资料”的终极场景。

1. **极速离线通关卡（Boarding & Border Pass）**
   * 用户可为单次即将出发的行程创建一张高对比度、纯离线展示的“通关聚合卡片”，一屏集中呈现边检与填表最高频信息：
     * 护照号（采用 **4 位空格分组大字** 排版，如 `E123 4567 8`，方便低光机舱抄写）。
     * 姓名拼音、出生日期、护照到期日、本次适用签证号（若涉及新旧护照，同步高亮两本护照号）。
     * 行程补充卡槽：本次航班号、目的地酒店英文及当地语言名称/地址/电话。
     * 附件直达槽：挂载 Visit Japan Web / SG Arrival Card 二维码、电子签 PDF 首页、回程机票确认单截图，点击全屏放大。
2. **纯血鸿蒙「实况窗（Live View）」独占联动**
   * 在出行前一键开启“通关护航模式”（或基于行程出发时间自动提示开启）。
   * 手机锁屏界面与状态栏常驻极简**实况窗胶囊**（仅展示目的地旗帜/代码与“通关卡就绪”，**锁屏态严禁明文暴露任何护照号码**）。
   * 到达边检柜台前，单手点击实况窗胶囊 $\rightarrow$ 触发人脸/指纹瞬时核验 $\rightarrow$ 直接唤起通关卡片并**自动将屏幕亮度调至最高**以便扫码；退出或息屏后自动恢复原亮度并即刻重新上锁。

### 模块 6：「护照 + 已有签证」动态叠加免签计算器
核心拉新钩子与核心爽点，解决“我有美签/日签/申根签，到底还能说走就走去哪”的痛点。

1. **动态规则叠加引擎**
   * 基于用户录入的**有效护照国籍** + **当前有效高含金量签证**（v1.0 重点覆盖：美签、申根签、日签、英签、加签、澳签、韩签），自动去重并汇总出完整的免签/电子签简化目的地列表。
   * 按“护照本身免签”、“落地签/电子签”、“**签证叠加额外解锁**”三类清晰分组，对叠加解锁的国家加上高亮签证标签（如：`🇺🇸 十年美签解锁`）。
2. **防客诉“前置条件标签”结构（关键风控）**
   * 严禁仅显示模糊的“免签”绿标，每条叠加规则必须结构化展示：
     * **签证类型门槛**：如 `需为 C 类多次有效贴纸签`
     * **激活状态要求**：如 `需已至少入境过一次签发国`
     * **单次最长停留**：如 `免签停留 7 天 / 30 天`
     * **附加前提提示**：如 `EVUS 须处于有效状态`、`需持联程离境机票`
     * **规则核验日期 + 轻量免责提示** + **一键纠错反馈入口**。
3. **规则库轻量化热更新（架构解耦）**
   * 安装包内置完整静态 JSON 兜底规则库，无网状态 100% 可用。
   * 支持极轻量只读 CDN 静默拉取规则 JSON 版本更新（用户可在隐私设置中开启“纯离线零联网模式”彻底关闭更新检查）。

### 模块 7：家庭多成员管理与鸿蒙桌面服务卡片
提升家庭场景客单价与日常高频触达。

1. **家庭证件管家**
   * 支持建立多成员档案（本人、伴侣、父母、子女），通过顶部胶囊快速切换成员视角。
   * **家庭出行证件包导出**：勾选本次出行的家庭成员与证件，一键生成带密码保护（可选）或带用途水印的**家庭出行汇总 PDF**，方便办理团体签证或应急备份。
2. **高颜值鸿蒙桌面服务卡片（Form Kit）**
   * 提供 `2x2`、`2x4` 两种高质感卡片规格，支持深浅色模式自适应：
     * **护照健康度与倒计时卡**：直观展示护照剩余有效期、空白页余量、最近即将过期的签证或 EVUS 提醒。
     * **免签版图概览卡**：展示“当前护照 + 已有签证共解锁 XX 个国家/地区”。
     * **隐私脱敏机制**：所有桌面卡片严格遵守脱敏原则，**默认绝不展示完整护照号与敏感照片**。

## 四、 数据安全、隐私与本地化架构设计

### 4.1 端侧安全防护体系（HarmonyOS NEXT）
1. **生物识别应用锁**：接入 `User Authentication Kit`（人脸/指纹/锁屏密码），支持“每次切回后台即刻锁定”或“自定义免密宽限期（如 1 分钟）”。
2. **防截屏与多任务模糊**：在证件详情页、原图预览页、通关卡页面调用鸿蒙窗口隐私模式 `setWindowPrivacyMode(true)`，阻止系统截屏/录屏，并在切换多任务视图时自动高斯模糊遮罩。
3. **本地加密存储**：结构化数据库使用鸿蒙端侧加密关系型数据库（`RelationalStore` 开启 `encrypt: true`），证件扫描原图及 NFC 提取证件照使用 AES-GCM 加密后存放在应用私有沙盒目录，不暴露于媒体库。

### 4.2 破解“纯本地与换机丢数据”悖论
* **本地端到端加密备份包（v1.0 必做）**：
  * 支持将所有成员数据、证件加密原图、行程记录打包导出为一个单一加密文件（如 `.passportvault`）。
  * 导出时强制用户设置独立主密码（基于 PBKDF2 / Argon2 派生密钥加密），用户可自行保存至网盘、电脑或发给微信文件传输助手；换新手机安装 App 后，导入该文件并输入主密码即可 100% 离线无损还原。

```json
  "rules": [

        "entryType": "MULTIPLE",

      "conditions": [
        "需持有效美国贴纸签证（有效期覆盖行程）",
        "护照有效期须在 6 个月以上",
        "须持有已确认的离境或赴第三国联程机票"
      ],
      "lastVerified": "2026-10-15",
      "referenceUrl": "https://..."
    }
  ]

```

### 5.2 证件血缘与关联实体关系（简化概念模型）
* `Member` (1) $\longleftrightarrow$ (N) `Passport`
  * `Passport` 包含字段：`status` (`ACTIVE` / `EXPIRED` / `REPLACED`), `replacedByPassportId`, `totalPages`, `pageStatusMap[]`
* `Passport` (1) $\longleftrightarrow$ (N) `Visa`
  * `Visa` 包含字段：`attachedPassportId`（用于检测是否贴在旧护照上）, `entryType`, `remainingEntries`, `maxStayDays`, `isActivated`
* `Visa` (1) $\longleftrightarrow$ (N) `SubCredential`（如 EVUS、eTA、港澳签注记录）

## 六、 商业化策略与权益划分

### 6.1 定价策略
* **采用模式**：免费下载 + 应用内购买（IAP 终身买断制为主，辅以低门槛年度会员降低尝鲜心理阻力）。
* **建议定价梯度**：
  * **Pro 终身买断**：首发早鸟价 ¥28–¥38，正式日常价 ¥48–¥68。
  * **Pro 年度订阅（可选备选）**：¥18 / 年（主要作用是作为价格锚点，衬托终身买断的超高性价比）。

### 6.2 免费版 vs Pro 版权益矩阵

| 功能模块 | 免费版 | Pro 会员（终身买断） |

## 七、 研发与版本迭代路线图（Roadmap）

### Phase 1：v1.0 首发版本（预计周期：5–7 周）
* **目标**：以“硬核防呆 + 极客质感 + 纯血鸿蒙原生体验”抢占生态早期红利与小红书/酷安口碑。
* **核心交付**：
  * 护照/签证全字段录入（MRZ 扫码 + NFC 芯片读取与原图提取）。
  * 主副证（EVUS/签注）关联与新旧护照同带预警 + 空白签证页可视化追踪。
  * 6 个月有效期红线预警 + 6 大核心签证（美/申根/日/英/加/澳）叠加免签查询（带条件标签）。
  * 一键防盗用水印与局部脱敏安全外发（零相册缓存）。
  * 离线边检通关卡 + 鸿蒙实况窗联动 + 2 款高颜值桌面卡片。
  * 生物识别锁、防截屏隐私模式、本地加密备份导出/导入、华为 IAP 买断内购。
* **前置合规确认**：在开工首周同步确认 AGC（AppGallery Connect）的 IAP 收款主体资质（企业/个体户）与 App ICP 备案流程。

### Phase 2：v1.1 – v1.2 深度体验与高客单转化期
* **核心交付**：
  * 申根 90/180 天滚动额度**可视化日历与未来行程沙盘推演**。
  * 申根 Cascade 阶梯晋级追踪（1 年 $\rightarrow$ 2 年 $\rightarrow$ 5 年多年签资格雷达）与日签/美签续签窗口提醒。
  * 签证申请「五年出境履历」一键格式化导出（适配 DS-160 / 申根 / 英签日期格式）+ 鸿蒙跨端剪贴板填表助手。
  * 华为云空间私有加密同步（可选开关，进一步降低换机门槛）。

### Phase 3：v2.0 社交裂变与情感留存期
* **核心交付**：
  * 高设计感年度出入境足迹海报、拟物化签证印章墙与全球已点亮/已解锁比例交互地图。
  * 家庭共享离线证件包（端到端加密碰一碰流转给伴侣鸿蒙设备）。
