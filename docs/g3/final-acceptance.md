## 二、审计二：经济预测真实性

**结论：不通过（证据不足），且这是可接受的有效结论**

| 判据 | 现状 |
|---|---|
| 真实指标序列 | 15 条（利润/营收/成本/PMI 六分项/工业增加值/期货 2 合约） |
| 观测版本 | **649 条**（2021-10 ~ 2026-09，47–50 期/序列） |
| STRICT 可用性 | **0%**：无一份文档能举证为"同期原件"，`value_evidence` 停在 C |
| RECONSTRUCTED 覆盖率 | 月度 as-of 从 19 条单调增至 179 条，2026-10 达 15/15 |
| OOS 执行 | **已执行**：`exp-steel-real-v1`，35 个决策样本，共同 OOS **仅 8 个** |
| OOS 结论 | **INSUFFICIENT_EVIDENCE**：8 个样本无法支持任何优势声明 |

**为什么不通过**：

1. **STRICT 结构性不可用**。第三方网页存档（archive.org / archive.today /
   memento）在本环境全部不可达，历史文档无法补证；唯一可行路径是"发布后 48h 内
   捕获"（已实现 `--as-published` 证据链），只能从今往后累积。
2. **OOS 样本过少**。已执行真实实验（RECONSTRUCTED PIT + 冻结 manifest +
   purge/embargo），但 35 个决策样本中只有 8 个落入共同 OOS 窗口；
   M01/M02 因内层无已公布验证样本被判 INSUFFICIENT_EVIDENCE。
   8 个样本上的 Brier 差异（M03 0.072 vs M00 0.875）是**小样本过拟合**，
   系统据此拒绝宣称优势。
3. **模型状态全部为 `NOT_VALIDATED / UNCALIBRATED / NO_EDGE`**，系统未宣称任何
   预测优势——这是设计意图。

**要转为"可评估"，需要**：更大的 OOS 窗口（当前 8 个样本；建议 ≥60）
与 R-011 区块 bootstrap 区间，以及 STRICT 样本 ≥24 个月（前向捕获累积中）。

## 三、审计三：ETF 回测可执行性

**结论：可执行性受限（数据驱动），不构成投资建议**

| 判据 | 现状 |
|---|---|
| 行情来源 | 新浪财经（第三方聚合，**C 级证据**） |
| 复权口径 | **不复权原始价**，已用腾讯 raw/qfq 双序列交叉验证（641 日最大差 0.000000） |
| 历史深度 | 钢铁/煤炭 ETF 2020-03 起；有色/沪深300 2018-12 起 |
| 分红 | 天天基金 F10 页 5 笔/标的，与 qfq 反推结果**独立一致**；已入账 |
| 回测引擎 | 次日开盘成交、佣金+滑点+现金利息、权重/换手上限、同成本基准、逐笔归因 |
| 完整回测（4.8 年） | 策略 **+14.22%**（年化 2.94%，Sharpe 0.30，MDD -18.1%，58 次调仓 3 笔成交） |
| 同期基准（沪深300ETF） | **-6.34%**（年化 -1.42%，Sharpe -0.08，MDD -31.9%） |
| 分红入账 | 45,284.82 元（27 笔公司行动） |

**为什么"受限"**：

1. 行情为**第三方 C 级来源**，合同 v1 的 `EvidenceClass` 无对应档位
   （已用 `MANUAL_UPLOAD` + reviewer 注明，需 contracts v2 增加 `VENDOR_PAGE`）。
2. `list_at` 由首个交易日推导，是**上市时点下界估计**，不是已核验主表。
3. 4.8 年样本上跑赢基准，但**仅 3 笔成交**，等价于"少量择时 + 长期持有"，
   不具备统计显著性；未做 bootstrap 区间与多重检验校正。
4. 结果对成本假设、阈值与起止日期敏感，未做参数敏感性分析。

**因此**：系统可以生成可复现的回测报告，但**不宣称策略可执行或有效**。
V-011 的正确产出就是这份"证据不足"的结论。

## 七、结论

**工程正确性**：通过。系统按契约运行，数据可溯源，失败模式显式。

**经济预测真实性**：不通过——但这正是任务书 §12.6 允许的有效结果。
系统没有、也不会宣称任何未经验证的预测优势。

**ETF 回测可执行性**：受限。引擎正确、数据可复现，但证据等级与样本长度
不足以支持可执行性结论。

**一句话**：这个项目交付的不是"一个能赚钱的模型"，而是"一个不会骗你的研究系统"。
它现在能明确告诉你：哪些数据可信、哪些不可信、哪些结论还不成立。
